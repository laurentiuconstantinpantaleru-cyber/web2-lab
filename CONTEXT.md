**Laboratory** (noun) — Practical coursework assignment or experimental project environment in this repository.
_Avoid_: workshop, homework, assignment.

**Ledger** (noun) — The collection of documentation files in `docs/agents/` tracking decisions, patterns, contracts, and open questions.
_Avoid_: wiki, knowledge base, notes.

**Decision** (noun) — An approved constraint that code in this repository must strictly obey.
_Avoid_: preference, suggestion, guideline.

**Pattern** (noun) — An approved or candidate reusable approach for implementing solutions in this codebase.
_Avoid_: template, recipe, snippet.

**Contract** (noun) — An explicit agreement defining interfaces, data formats, or boundary promises provided or consumed by this repository.
_Avoid_: protocol, API spec, interface agreement.
